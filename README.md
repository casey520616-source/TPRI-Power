台灣電力最新情報分析平台（淨零工程版）使用說明書
歡迎使用「台灣電力最新情報分析平台」。本平台專為電網營運商 (TSO/ISO)、淨零工程師與政策決策者設計，提供即時電力情報監控、AI 智慧分析與會員化數據管理功能。

一、 系統快速入門
1. 帳號登入與註冊
會員登入/註冊：點擊右上角「登入」按鈕，可於雙頁籤切換：

登入：輸入電子郵件與密碼。

註冊：輸入姓名、電子郵件、設定密碼並進行確認密碼。

訪客體驗：點擊「以訪客身份體驗」，無需帳號即可瀏覽系統基礎儀表板與離線備份數據。

2. 介面視覺與主題
系統採用 溫暖淺色系 (Warm Light Theme) 設計，背景以暖米白與高透光毛玻璃質感呈現，搭配高對比深暖灰文字，適合長時間數據閱讀與分析。

二、 核心功能操作指南
1. 即時電網與電力情報儀表板 (Dashboard)
關鍵指標面板：即時顯示目前全台備轉容量率、綠能發電佔比、電網頻率穩定度與碳排放強度等關鍵 KPI。

情報清單區：列出最新發布的電力技術情報，包含：

構網型逆變器 (Grid-forming Inverter) 與合成慣性部署

區域電網壅塞（如南電北送瓶頸）分析

儲能系統 (BESS) 輔助服務調度狀況

2. AI 智慧分析模組 (Gemini-3.5-flash)
啟動 AI 分析：在控制面板點擊 「觸發 Gemini-3.5-flash 分析」 按鈕。

極速報告生成：系統將呼叫 Gemini-3.5-flash 高速引擎，於 1 秒內自動產出最新一週的電網風險評估、供需趨勢與淨零策略建議。

自動同步：生成後的情報將即時寫入雲端資料庫，並同步更新至全平臺儀表板。

三、 常見問題與排除 (FAQ)
Q1: 畫面顯示「Missing or insufficient permissions」警告紅字？
原因：此為 Firebase Cloud Firestore 資料庫權限阻擋。

排除方式：

請前往 Firebase Console 進入您的專案。

點擊 Firestore Database -> Rules (規則) 頁籤。

將規則調整為開發測試模式（allow read, write: if true;）並發布。

重新整理網頁即可恢復正常連線。

Q2: 網路斷線或資料庫連線失敗時還能使用嗎？
答案：可以。系統具備 離線備份機制 (Offline Fallback)，當網路不穩定或權限尚未開放時，會自動切換顯示預設的靜態數據，保證系統運作順暢不當機。
